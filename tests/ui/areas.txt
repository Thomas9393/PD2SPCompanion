# Which UI cases a changed file calls for (tests/check.py changed): a pattern of paths, a tab, the tags of the
# cases to run (tests/ui/units; kit.ps1 says what a case is). * stands for anything, folders included.
# Kept beside the cases, so a case added for an area is found by the files of that area.
#
# Narrow before wide: a file that has its own line calls for its own cases and, by a folder's line under it,
# for the folder's too. A unit file's own change calls for that file's cases, by the tag it wears - each wears
# its script's name. `run.ps1 -List` shows every case with its tags.
