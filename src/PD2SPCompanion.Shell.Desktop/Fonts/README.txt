Project Diablo II Single Player Companion - your own title font

The companion's titles and headings are set in Cinzel, which ships with it.

To use another font, put its file (.ttf or .otf) in this folder and start the companion again.
Settings > Folders shows which font is in use. Remove the file to go back to Cinzel.

Two fonts are checked with the companion: Cinzel, which is built in, and AvQest.

- AvQest is a free lookalike of the game's own lettering, by GemFonts (Graham Meade), and the pages are
  laid out for a font of its size. It is not shipped with the companion: its author asks that it be passed
  on only as his own download. If you like the classic look, download it yourself and put AvQest.ttf here.
- Any other font is used as it is, at your own risk: nothing is resized to fit, so a wider or taller
  font may crowd buttons and tabs, and one without small capitals shows ordinary lowercase.
- A family with several weights: put them all here (Regular and Bold); bold titles then use the real Bold.
- With more than one family here, the first file by name decides.

Fonts are their authors' work: use one you are allowed to use.
